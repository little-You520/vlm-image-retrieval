# 🔍 VLM 跨模态图像检索系统

基于 **CLIP (ViT-B/32)** 和 **FAISS** 构建的文本搜图 Demo。输入一段文字描述，系统自动在图片库里找出最匹配的 Top-K 张图片。

## 📊 实验结果

| **Baseline** | CLIP (ViT-B/32) 零样本 | 89.05% | 98.10% | 92.87% | ✅ 基线 |

| **改进点 1** | CLIP (ViT-L/14) 零样本 | 87.62% | 99.05% | 92.01% | ⚠️ 负收益（低分辨率下大模型过拟合） |

| **改进点 2** | CLIP (ViT-B/32) **领域微调** | **100.00%** | 100.00% | 100.00% | 🚀 **完美拟合** |

| **改进点 3** | CLIP (ViT-B/32) **+ Query Expansion** | **90.00%** | 97.50% | 94.03% | ✅ 零样本稳定提升 |

### 实验结论
1. **Baseline (89.05%)**：CLIP 在 CIFAR-10 上具备较强的零样本检索能力，但在细粒度类别（如猫 vs 狗）上存在混淆。
2. **改进点 1 (87.62%)**：换用 ViT-L/14 大模型后性能反而下降，证明 **模型容量需与数据质量匹配**——CIFAR-10 的 32x32 低分辨率无法发挥大模型优势。
3. **改进点 2 (100.00%)**：通过微调视觉编码器最后 3 层，模型完美适配了 CIFAR-10 的数据分布。该结果验证了 **领域微调的有效性**，同时也受限于数据集规模（10 类，2000 张）。
4. **改进点 3 (90.00%)**：在零样本 Baseline 上使用同义词扩展查询，R@1 提升 0.95%，证明 **查询优化** 在真实场景（如用户输入模糊）中具有实用价值。-

## 🧠 项目核心逻辑（这系统是怎么工作的？）

抛开复杂的数学，这个项目只做了 4 件大事：

### 1. 📂 数据整理（预处理）
把杂乱的数据集整理成标准清单。
- 遍历 CIFAR-10 图片，保存到本地。
- 生成 `manifest.jsonl` 文件，记录**每张图片的路径**和**对应的标签**（告诉程序：这张图叫猫，那张图叫狗）。

### 2. 🧬 提取“数字指纹”并建索引（核心）
图片不能直接搜索，必须先变成“数字”。
- 把 2000 张图喂给 **CLIP 模型**，每张图变成一串 **512 维的向量**（相当于人类的指纹）。
- 把这些“指纹”存入 **FAISS 向量索引**（相当于图书馆的智能目录）。有了它，搜索时不用翻遍所有书，直接查目录就能瞬间定位。

### 3. ⌨️ 文字转“指纹”并检索
- 用户输入文字（如“一只猫”），CLIP 把文字也变成同样的 512 维向量。
- 拿着文字的“指纹”去 FAISS 目录里比对，找出向量距离最近的 Top-K 张图片。

### 4. 📈 评测与调优
- 用 210 个测试查询计算 **R@K**（召回率），量化模型好坏。
- 通过失败分析饼图，发现主要错误集中在**猫vs狗**、**马vs鹿**等视觉相似类别，为后续微调和 Query Expansion 指明方向。

## 🛠️ 快速开始（如何复现）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 准备数据（生成 2000 张图片和 manifest）
python src/preprocess.py

# 3. 提取特征并构建 FAISS 索引
python src/build_index.py

# 4. 文字搜图测试
python src/search.py --query "a photo of a cat" --top_k 5

# 5. 运行完整评测（生成 R@1, R@5, MRR）
python src/eval.py

# 6. 失败案例分析（生成饼图）
python src/analyze.py
