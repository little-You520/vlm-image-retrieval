# Baseline 评测报告 (CIFAR-10)

## 1. 模型与数据
- **模型**: CLIP (ViT-B/32)
- **数据集**: CIFAR-10 (2000 张图片, 10 类)
- **索引**: FAISS (内积相似度)

## 2. 量化指标 (基于 210 个测试查询)
- **R@1**: 89.05%
- **R@5**: 98.10%
- **R@10**: 100.00%
- **MRR**: 92.87%

## 3. 失败案例分析
共发现 **23** 个 R@1 失败案例（约占 10.95%）。

主要混淆情况如下（饼图见 `results/failure_analysis.png`）：

| 混淆对 | 次数 |
|--------|------|
| cat→dog | 6 |
| dog→automobile | 6 |
| horse→deer | 6 |
| automobile→truck | 1 |
| automobile→cat | 1 |
| dog→deer | 1 |
| dog→cat | 1 |
| truck→automobile | 1 |

**原因分析**：
- CIFAR-10 图片分辨率仅 32x32，CLIP 预训练于 224x224 高清图，导致低分辨率下细粒度特征难以区分。
- 猫与狗视觉相似度高，在低分辨率下更易混淆。
- 狗被误识别为汽车（6 次）较异常，可能与图像中背景或车辆相关物体有关。

## 4. 改进方向
- **换用更强 Backbone**（如 ViT-L/14）提升特征提取能力。
- **领域微调**：在 CIFAR-10 上微调 CLIP，适应低分辨率。
- **Query Expansion**：用同义扩写提高召回率。

## 5. 结论
Baseline 表现良好（R@1 达 89%），但在细粒度分类上存在混淆，尤其猫/狗/鹿/马之间。后续改进将针对性解决这些问题。
